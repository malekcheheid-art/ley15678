# Actividad 10 - Conciencia digital, algoritmos y marco legal (Ley 15.678)

Repositorio de la Actividad 10 de Laboratorio de Programación (LPR 5° Año),
E.E.S.T. N° 100. La actividad consiste en relacionar la Ley 15.678
(regulación del uso de celulares en el aula) con la programación de un
algoritmo de toma de decisiones.

## Estructura del repositorio

```
.
├── README.md
├── src/
│   └── leyicelulares.py    # Simulador de normativa de celulares (Python)
├── docs/                   # Informe APA v7 en PDF
├── capturas/               # Capturas de pantalla del código y su ejecución
└── consigna/               # PDF de la consigna de la actividad
```

## Requisitos

- Python 3.x
- Editor de código (VS Code recomendado)

## Ejecución

```powershell
python src/leyicelulares.py
```

## Contenido de la actividad

1. Introducción: la Ley 15.678 y su aplicación en el aula.
2. Desafío: diagrama de flujo (opción A) y script en Python (opción B).
3. Cuestionario de reflexión y técnica (3 preguntas).
4. Informe APA v7 en PDF para subir a Moodle.
